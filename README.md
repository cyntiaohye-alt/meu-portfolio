# Meu Portfólio Pessoal 💜

**Aluna:** Cyntia Ohye

## Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar meu perfil, minhas habilidades e alguns projetos realizados durante meus estudos no curso Técnico em Desenvolvimento de Sistemas.

O site foi desenvolvido utilizando HTML, CSS e Bootstrap, com um design moderno e cores em tons de roxo e lavanda.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- GitHub Pages

## Estrutura do projeto

O portfólio possui as seguintes seções:

- **Início:** apresentação inicial.
- **Perfil:** informações sobre a estudante.
- **Habilidades:** apresentação das tecnologias estudadas.
- **Projetos:** exemplos de trabalhos desenvolvidos.
- **Contato:** informações para contato.

O menu de navegação permite acessar cada seção do site. Também possui um menu responsivo, que se adapta a telas menores.

## Recurso novo adicionado

Foi adicionada uma animação aos cartões de habilidades e projetos.

Quando o usuário passa o mouse sobre um cartão, ele se movimenta levemente para cima e recebe uma sombra, criando um efeito visual interativo.

## Como o recurso foi implementado

A animação foi desenvolvida utilizando CSS, por meio das propriedades:

- `transition`: cria uma transição suave.
- `:hover`: ativa o efeito quando o mouse passa sobre o cartão.
- `transform: translateY(-8px)`: movimenta o cartão para cima.
- `box-shadow`: adiciona uma sombra ao cartão.

Também foi criada uma seção de habilidades para complementar a apresentação pessoal.
